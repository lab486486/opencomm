# 드라마 자동 포스팅 시스템 가이드 (최종 개선판)

드라마 실시간 방송 정보 포스팅에 최적화된 자동화 도구입니다.

## 1. 작동 방식
1. 워드프레스의 **'드라마_지시'** 카테고리에 새 글을 작성합니다.
2. 아래 양식에 맞춰 정보를 입력합니다.
3. 파이썬 스크립트(`drama_main.py`)를 실행하면 제미나이가 정보를 수집하여 고퀄리티 포스팅을 발행합니다.

## 2. 지시글 작성 양식 (워드프레스 '드라마_지시' 카테고리)
---
드라마 제목:
방송국:
대표 썸네일 URL:
방송 기간:
방송 시간:
방송 회차:
주요 출연진:
연출 및 작가:
시놉시스 및 줄거리:
유튜브 영상 주소:
실시간 방송 주소:
---

## 3. 주요 개선 사항
- **넷플릭스 스타일 레이아웃**: 포스터(좌) + 상세정보(우) 가로 배치 및 세로 중앙 정렬.
- **정보 정확도**: '참고 사이트'와 '참고 내용'을 분석하여 최신 정보를 정확히 반영.
- **콘텐츠 풍성도**: 작가/연출 및 등장인물 분석 섹션 분량 대폭 강화 (최소 2문단 이상).
- **SVG 버튼**: 📺 아이콘이 포함된 깔끔한 실시간 시청 버튼 (줄바꿈 오류 해결).
- **자동 상태 관리**: 처리가 완료된 지시글은 자동으로 '임시글(draft)'로 변경되어 중복 처리를 방지합니다.

## 4. 실행 방법
```bash
python3 drama_main.py
```
*`.env` 파일에 워드프레스 정보와 Gemini API 키가 설정되어 있어야 합니다.*
